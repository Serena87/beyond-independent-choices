
# Raw data

The raw data used in this project comes from the Kaggle competition:

H&M Personalized Fashion Recommendations

https://www.kaggle.com/competitions/h-and-m-personalized-fashion-recommendations/data

The dataset is not included in this repository because access and redistribution
are governed by the Kaggle competition rules.

To reproduce the analysis:

1. Register or sign in to Kaggle.
2. Accept the H&M Personalized Fashion Recommendations competition rules.
3. Download the competition data.
4. Place the following files in this directory:

   - `transactions_train.csv`
   - `articles.csv`

The analysis does not require `customers.csv` or the product image files.
